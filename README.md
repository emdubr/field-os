# FIELD/OS 1.3

TAP V2 companion interface. GitHub Pages deploys from main / root.

Desktop uses one persistent side menu; phone uses the bottom tabs. All 16 modules share detailed terminal panels. Supplemental readouts use local app state; hardware and mesh remain explicitly unconnected/demo.

Assets: index.html, styles.css, workstation.css, app.js, workstation.js, survival-data.js, manifest.webmanifest, icon.svg, sw.js.

Existing v1.2 local-storage keys are preserved. Service worker uses versioned caches and refreshes assets online, falling back to cache offline. Physical hardware testing remains outstanding.
