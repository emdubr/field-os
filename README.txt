FIELD/OS v1.2 — GitHub Pages / static hosting ready

IMPORTANT: upload THESE FILES directly to the root of your website/repository.
index.html must be at the root — do not upload a folder that contains index.html unless your host is configured to serve that folder.

GitHub Pages quick setup:
1. Create/open a repository.
2. Upload all files from this folder to the repository root.
3. Settings > Pages.
4. Build and deployment: Deploy from a branch.
5. Branch: main, folder: /(root), then Save.
6. Wait for GitHub to show the published URL.
7. Open that exact URL in Safari on iPhone.
